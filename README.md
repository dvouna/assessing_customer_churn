## Project Overview 
This project delves into the factors driving customer churn in the Indian telecom industry, analyzing behavioral and demographic data from two robust datasets provided by four major providers: Airtel, Reliance Jio, Vodafone, and BSNL.

By applying machine learning models, we aim to predict which customers are likely to leave and identify the underlying causes of churn. These insights are critical for telecom companies seeking to boost customer retention, improve service quality, and tailor their strategies to evolving user needs.
